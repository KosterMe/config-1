# Эмулятор командной оболочки UNIX

Практическая работа по дисциплине «Конфигурационное управление», вариант №1.

## Общее описание

Консольное приложение на Java, которое имитирует работу командной строки
UNIX-подобной ОС. Эмулятор выводит приглашение, читает команды пользователя,
выполняет их и сообщает об ошибках.

Это минимальный прототип (REPL): команды `ls` и `cd` пока являются
заглушками, но диалог с пользователем уже работает.

## Этапы

| Этап | Что сделано | Тег |
|---|---|---|
| 1. REPL | приглашение, парсер, заглушки `ls` и `cd`, команда `exit` | `stage-1` |

Каждый этап — отдельный коммит, отмеченный тегом `stage-N`.

## Требования

- JDK 17 или новее (`javac` и `java` должны быть доступны в `PATH`).
- Сторонние библиотеки не используются.

## Сборка, запуск и тесты

| Действие | Linux / macOS | Windows |
|---|---|---|
| Сборка и запуск эмулятора | `./run.sh` | `run.bat` |
| Сборка и запуск тестов | `./test.sh` | `test.bat` |

Скрипты сами компилируют исходники, классы складываются в папку `out/`
(она в `.gitignore`). Тесты написаны без внешних библиотек и запускаются
классом `TestRunner`: он печатает число успешных и проваленных проверок,
при провале код завершения — 1.

Эмулятор работает, пока не будет выполнена команда `exit` или не закончится
ввод (Ctrl+D в Linux/macOS, Ctrl+Z и Enter в Windows).

## Функции

### Приглашение к вводу

Приглашение строится по реальным данным ОС: `имя_пользователя@имя_компьютера:~$`.
Имя пользователя берётся из `user.name`, имя компьютера — из переменных
окружения `COMPUTERNAME`/`HOSTNAME` или у сетевой подсистемы.

### Парсер

Строка ввода разделяется по пробелам: первое слово — команда, остальные —
аргументы. Лишние пробелы игнорируются, пустые строки пропускаются.

### Команды

| Команда | Описание |
|---|---|
| `ls [аргументы]` | Заглушка: выводит своё имя и аргументы |
| `cd [аргумент]` | Заглушка: выводит своё имя и аргументы (не больше одного аргумента) |
| `exit [код]` | Выход с указанным кодом (по умолчанию — код последней команды) |

### Обработка ошибок

| Ситуация | Сообщение |
|---|---|
| Неизвестная команда | `foo: command not found` |
| `cd` с несколькими аргументами | `cd: too many arguments` |
| `exit` с нечисловым аргументом | `exit: abc: numeric argument required` |
| `exit` с несколькими аргументами | `exit: too many arguments` |

После ошибки эмулятор продолжает работу, код завершения команды равен 1.

## Структура проекта

```
src/emulator/            исходный код
  Main.java              точка входа
  Shell.java             цикл REPL и выполнение команд
  ShellSession.java      состояние оболочки
  CommandParser.java     парсер строки ввода
  SystemInfo.java        имя пользователя и компьютера
  commands/              реализации команд
tests/emulator/          тесты (запуск через TestRunner)
```

## Пример использования

```
$ ./run.sh
kostya@DESKTOP-1PQVNLF:~$ ls
ls: stub, arguments: []
kostya@DESKTOP-1PQVNLF:~$ ls -l /home
ls: stub, arguments: [-l, /home]
kostya@DESKTOP-1PQVNLF:~$ cd docs
cd: stub, arguments: [docs]
kostya@DESKTOP-1PQVNLF:~$ cd a b
cd: too many arguments
kostya@DESKTOP-1PQVNLF:~$ hello world
hello: command not found
kostya@DESKTOP-1PQVNLF:~$ exit abc
exit: abc: numeric argument required
kostya@DESKTOP-1PQVNLF:~$ exit 0
```
